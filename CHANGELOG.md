# Changelog

## 0.1.3 - 2026-10-23

- Added a Start with Windows option to the tray menu

## 0.1.2 - 2026-10-23

- The global hotkey can be changed from the tray menu and is remembered between runs
- If the hotkey is already taken at startup, ScreenMark asks for another one instead of exiting

## 0.1.1 - 2026-10-23

- The toolbar is excluded from screenshots and screen recordings; this needs Windows 10 version 2004 or later

## 0.1.0 - 2026-10-22

Initial release.

- Transparent drawing overlay toggled with `Ctrl+0`, one window per monitor
- Rectangle, ellipse, arrow, freehand and text tools in red, green and blue
- Floating toolbar with undo, redo, clear all and close
- Keyboard shortcuts: `Esc` closes the overlay, `Ctrl+Z` undoes, `Ctrl+Y` redoes
- Mouse wheel is forwarded to the window under the overlay
- System tray icon with an Exit command
- Single instance per user session
